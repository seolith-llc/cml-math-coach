> #step002 add the missing palindrome and digit placement puzzles. How can I open it in my kids iPad ?

## Response summary

**New answer types** (`src/core/answer.ts`, `types.ts`)
- `digits`: a full digit string. Accepts `6897986`, `6,897,986`, `6 8 9 7 9 8 6` or spoken "six eight nine…".
- `placement`: one digit per slot. **Any** arrangement that meets the rules is accepted. Feedback names the problem
  ("The line A-C-E adds to 12, not 10", "Use each digit exactly once").
- Palindrome-specific feedback: wrong length, or "read it backwards, it is not the same".

**New topics** (`src/content/generators/placement.ts`, total now 39)
- **Palindromes:** L1 spot the palindrome (multiple choice). L2 complete a palindrome using all given digits: Grade 2 is 5 digits from 3, Grade 3 is 7 digits from 4. Clues are revealed until exactly one answer fits, then extra clues are removed. G3 L3: smallest palindrome greater than N.
- **Digit placement & magic sums:** L1 corner-square (same number in all 4 corners). L2 plus-shape with 5 consecutive digits. G3 L3 triangle with digits 1–6. Hints teach the "shared circle counted twice" idea.

**UI**
- `src/ui/placementBoard.ts`: tap a circle, then a digit (touch, mouse, keyboard). Voice: say the digits for circles A, B, C… in order. Used in practice, review and mock meets.

**iPad**
- Speech is unlocked on the first tap (iOS needs a user gesture before read-aloud).
- iOS Home Screen meta tags added. On the Home Screen app, the home page explains that voice answers need Safari (WebKit doesn't give speech recognition to Home Screen web apps).
- `.github/workflows/deploy-pages.yml`: test, build and deploy to GitHub Pages on every push to `main`.
- `docs/IPAD.md`: step-by-step guide (deploy via GitHub Pages or Netlify Drop, open in Safari, allow the mic, Add to Home Screen, helpful iPad settings).

**Verification:** 257 tests pass. New tests check that each palindrome template has exactly one answer, that every valid board arrangement is accepted and every invalid one rejected, and the corner-square arithmetic. The build passes. Playwright smoke test at iPad size with touch: board taps, check, palindrome feedback, no console errors.
