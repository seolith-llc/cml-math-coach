**Decisions (asked the user):** **Amazon SES**; send **Sunday about 6 pm US Central**.

**Design**
- **Scheduling:** Pages Functions have no cron, so `.github/workflows/weekly-email.yml` runs at both Sunday-evening UTC slots (07 past 23:00 Sun and 00:00 Mon). It calls `POST /api/weekly` (bearer `CRON_SECRET`, constant-time compare) in batches of 25.
  - The server sends only in the Sunday 5 pm to Monday 6 am America/Chicago window.
  - Each family is marked with a week key, so it gets at most one email per week, through daylight-saving changes and late cron runs.
- **SES:** `server/ses.ts` calls the SES v2 API with SigV4 on WebCrypto (no SDK).
  - Tested against the AWS documentation vector and the `aws4` reference library.
  - Adds List-Unsubscribe and one-click headers, and retries without them if SES rejects headers.
- **Opt-in:** the parent sets an email on the PIN-protected dashboard. A confirmation link is sent (token stored as sha256, 3-day expiry, single use).
  - GET pages only show a button and the change happens on POST, so mail scanners can't confirm or unsubscribe.
  - Confirmation and test emails are capped at 5 per day.
  - Dashboard actions: email-set, email-test, email-stop.
- **Content** (`server/digest.ts`) reuses the dashboard's summarize():
  - Subject like "Sam's math week: 27 problems, 63% right first try", or a quiet-week variant.
  - KPIs vs last week, an email-safe 7-day stacked bar chart, needs-help and strong topics, this week's mock meet, up to 3 mistakes (question, answer given, correct answer), ideas for next week, and an unsubscribe footer.
  - Plain-text alternative included. All user content is HTML-escaped. Families inactive for 4+ weeks are skipped.
- **D1:** migration `0002_weekly_email.sql` (ALTER TABLE). `scripts/ensure-d1.mjs` now records applied migrations in a `_migrations` table.
- **CI:** the deploy copies `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `CRON_SECRET` (secrets) and `AWS_REGION`, `MAIL_FROM`, `MAIL_REPLY_TO` (variables) into Pages secrets. `APP_URL` is in wrangler.toml [vars].
