- So there is no migration and no API change, and the server code is untouched.

**Child device**

**Dashboard**
- `insights.lastRounds()` returns the rounds newest first, with the score (e.g. "0 → 2 of 10") and each question's type, result, fix and first answer. It tolerates old or partial snapshots.

- Tapping a question shows the child's answer against the right one and plays the animated explanation, reusing `answerReview`. Tapping it again closes it.
- Only one explanation plays at a time, and it stops on refresh or when leaving.
