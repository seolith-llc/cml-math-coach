## Response summary

**Finding:** the explanation player (`src/ui/player.ts`) did have both controls, but they were hard to find. It was reproduced locally on the Test screen at iPad size (Learn mode → Answer).
- Pause was a small, thin icon, the same as Back, Next and Replay, with nothing marking it as the main control.
- The voice toggle was a plain speaker at the far right that only changed when tapped, so it read as "play sound", not "mute".
- A second, identical speaker (the card's Read aloud) sat just below it.

**Change (no helper text, per the UI copy rule):**
- `player.ts`: play/pause is now the main control (`play-main`). Mute moves right next to it. Its label is "Mute"/"Unmute" (it was "Voice on"/"Voice off"), it has `aria-pressed`, and an `off` class when muted.
- `styles.css`: play/pause is a 52 px filled accent circle using `--accent-ink` for the icon. Muted shows the crossed speaker on `--fill`.
- The same player is used everywhere (Practice, Review, Test, the round end and the parent dashboard), so the fix applies to all of them.

**Verification**
- Playwright at 820×1180, light and dark: Pause becomes Play; Mute becomes Unmute (pressed); screenshots checked.
